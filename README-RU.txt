БЕСПЛАТНЫЙ ХОСТИНГ САЙТА STEEL-SERVES.BY НА RENDER
===================================================

Пошаговая инструкция. Выполните по порядку — это займёт 10–15 минут.
Ничего платить не нужно. В конце вы получите ссылку вида
https://steel-serves-demo-free.onrender.com и рабочую админку.

=========================================================
ЧТО ВЫ ПОЛУЧИТЕ И КАКИЕ ЕСТЬ ОГРАНИЧЕНИЯ
=========================================================
Плюсы:
- сайт целиком, включая админку, форму заявок и вход по /login;
- HTTPS-сертификат от Render (настраивать не нужно);
- адрес на onrender.com можно открыть с телефона и показать заказчику;
- письма НИКУДА не отправляются — заявки сохраняются в админке.

Ограничения бесплатного тарифа Render:
- 750 часов в месяц на аккаунт (одного сайта хватает на весь месяц);
- после 15 минут без посещений сервис «засыпает», первый заход после
  паузы занимает до 1 минуты — это нормально, просто подождите;
- НЕТ постоянного диска: при каждом перезапуске контент возвращается
  к исходному, загруженные фото и заявки исчезают. Для показа сайта
  заказчику этого достаточно; для реальной работы нужен платный план.
- Пароль создаётся заново из переменной BM_ADMIN_PASSWORD при каждом
  старте — но он всё тот же, пока вы не измените переменную.

Почему именно Render: это один из немногих хостингов, где PHP-сайт с
админкой можно поднять бесплатно. GitHub Pages, Netlify и Vercel PHP
не запускают — там можно разместить только статичный HTML без админки.

=========================================================
ШАГ 1. СОЗДАЙТЕ АККАУНТ GITHUB
=========================================================
1. Откройте https://github.com/signup
2. Введите:
   - Email — ваша Почта;
   - Password — придумайте надёжный (сохраните в менеджере паролей);
   - Username — например, steel-serves-demo.
3. Пройдите проверку (cartcha), подтвердите почту: придёт письмо со ссылкой.
4. Нажмите ссылку в письме — аккаунт готов.

=========================================================
ШАГ 2. СОЗДАЙТЕ РЕПОЗИТОРИЙ
=========================================================
1. Войдите в GitHub, нажмите зелёную кнопку «New» (или
   https://github.com/new).
2. Repository name: steel-serves-demo
3. Description: можно оставить пустым.
4. Выберите Private или Public — всё равно. Если в репозиторий не будет
   пароля, публичность безопасна. Рекомендую Private.
5. НЕ ставьте галочки «Add a README», «Add .gitignore», «Choose a license» —
   они создадут лишние файлы. Нажмите «Create repository».

=========================================================
ШАГ 3. ЗАГРУЗИТЕ ФАЙЛЫ САЙТА В РЕПОЗИТОРИЙ
=========================================================
Самый простой способ без установки Git:

1. Распакуйте архив steel-serves-render-free-kit-2026-11-21.zip
   в отдельную папку, например C:\Users\ulian\steel-serves-free.
2. В открытом репозитории GitHub нажмите «uploading an existing file»
   (или «Add file» → «Upload files»).
3. Перетащите туда ВСЁ содержимое распакованной папки — не саму папку,
   а файлы и вложенные папки:
     Dockerfile
     render.yaml
     README-RU.txt
     SECURITY-CHECKS-RU.txt
     .dockerignore
     .gitignore
     bin\           (папка с тремя файлами)
     config\        (папка с двумя файлами)
     site\          (папка сайта)
4. Нажмите зелёную кнопку «Commit changes».

Проверьте в списке файлов: в корне должны быть Dockerfile и render.yaml,
а внутри site\ — index.html, admin\, data\, assets\. Если вы загрузили
внутреннюю папку steel-serves-free целиком, Render не найдёт Dockerfile —
удалите лишний уровень через веб-интерфейс GitHub.

ВАЖНО: в папке site\data\ НЕ должно быть файла config.php. Если он там
появился — удалите его перед загрузкой. Пароль создастся сам при запуске.

=========================================================
ШАГ 4. СОЗДАЙТЕ АККАУНТ RENDER
=========================================================
1. Откройте https://dashboard.render.com/register
2. Нажмите кнопку «GitHub» — так Render сразу получит доступ к вашему
   репозиторию и не попросит подтверждать почту отдельно.
3. Разрешите доступ к репозиторию steel-serves-demo.
4. Если Render попросит выбрать план — выберите Free / Hobby.
   Кредитную карту вводить НЕ нужно для бесплатного сервиса.

=========================================================
ШАГ 5. ЗАПУСТИТЕ ДЕПЛОЙ
=========================================================
1. В панели Render нажмите «New +» → «Blueprint».
2. В списке репозиториев выберите steel-serves-demo → «Connect».
3. Render прочитает render.yaml и покажет один сервис
   «steel-serves-demo-free». Нажмите «Apply» / «Create Resources».
4. Откроется форма с переменной окружения BM_ADMIN_PASSWORD.
   Введите стартовый пароль, который я передал вам отдельным сообщением
   (он же записан в файле dist\ADMIN-PASSWORD-RU.txt основного архива).

   Можно придумать свой пароль, но не короче 12 символов: буквы, цифры
   и знак. Обязательно запишите его — в файле он не хранится, только хеш.
5. Нажмите «Create» / «Deploy». Начнётся сборка контейнера — 2–5 минут.
   В логах будут видны шаги apt-get, docker-php-ext-install, затем запуск.

Если Render не показывает поле пароля: зайдите в сервис → Settings →
Environment → добавьте переменную BM_ADMIN_PASSWORD со значением пароля
и нажмите «Save Changes» — сервис перезапустится.

=========================================================
ШАГ 6. ПРОВЕРЬТЕ, ЧТО ВСЁ РАБОТАЕТ
=========================================================
Откройте выданный адрес (он указан на странице сервиса сверху).

1. https://steel-serves-demo-free.onrender.com/
   → должна открыться главная страница «База-Металла».
   Первый запуск после сна может занять до минуты — подождите.

2. https://steel-serves-demo-free.onrender.com/healthz
   → должно быть просто слово ok. Это проверка для Render; если она
   не пройдёт, Render пометит деплой как неудачный.

3. https://steel-serves-demo-free.onrender.com/login
   → должно произойти перенаправление на /admin/ и открыться форма входа.

4. Введите пароль из шага 5 → откроется панель управления.
   В правом верхнем углу нажмите «Сохранить» — всё должно сохраниться.

5. Откройте «Настройки» → «Пароль» и смените стартовый пароль на свой.
   Новый пароль — не короче 12 символов. После смены старый перестанет
   работать. Запишите новый пароль.

6. Убедитесь, что публичной ссылки на админку на сайте нет: вход только по /login.

7. Отправьте тестовую заявку с главной страницы. Письмо НЕ уйдёт, но
   заявка появится в разделе админки «Заявки». Так мы не трогаем почту
   perilov.kuha@gmail.com.

=========================================================
ШАГ 7. ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
=========================================================
«Build failed» на сборке
   Откройте вкладку Logs → разверните ошибку. Чаще всего не загрузился
   Dockerfile или render.yaml. Проверьте шаг 3.

«502 Bad Gateway» / долго открывается
   Контейнер просыпается после сна. Подождите 60 секунд и обновите страницу.
   Если не помогло — Logs → последние строки.

«ERROR: set BM_ADMIN_PASSWORD» в логах
   Не задана переменная окружения. См. конец шага 5.

Сайт открылся, но /login даёт 404
   Не подключился mod_rewrite. Проверьте, что в Dockerfile есть строка
   a2enmod rewrite, и перезапустите деплой.

Правки пропали после перезапуска
   Так работает бесплатный план без диска. Это ожидаемо. Для сохранения
   правок нужен платный план — скажите мне, подготовлю комплект.

=========================================================
КОГДА ДЕМО ЗАКОНЧИТСЯ
=========================================================
1. Render → ваш сервис → Settings → Delete Service. Это остановит расход
   часов и закроет публичный доступ к админке.
2. GitHub → репозиторий → Settings → удалить, если он больше не нужен.
3. В Render → Settings → Account → Connected Accounts → отзовите доступ
   к GitHub.
